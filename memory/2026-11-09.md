## Sửa lỗi màn hình trắng (White Screen) khi đổi avatar học sinh
- **Nguyên nhân chính**: Trong file `src/components/common/AvatarUploadModal.tsx`, câu lệnh `if (!isOpen) return null;` được đặt TRƯỚC hook `useMemo` (dùng để tính `takenAvatarMap` và `genderMatchedPresets`). Khi modal chuyển trạng thái từ đóng (`isOpen = false`) sang mở (`isOpen = true`), số lượng hooks trong React component thay đổi từ 5 lên 6, vi phạm nghiêm trọng quy tắc **React Rules of Hooks** (`Error: Rendered more hooks than during the previous render.`). Điều này khiến toàn bộ ứng dụng React bị unmount và văng ra màn hình trắng hoàn toàn. Phía giáo viên không bị vì modal giáo viên (`TeacherAvatarModal`) có cấu trúc hook đúng thứ tự.
- **Giải pháp xử lý**:
  1. Đưa tất cả React hooks (`useState`, `useRef`, `useEffect`, `useMemo`) lên đỉnh component, chạy vô điều kiện trước mọi câu lệnh `return`.
  2. Bổ sung các guard phòng thủ an toàn cho object `student` (`student?.avatarUrl`, `student?.maHS`, `student?.gioiTinh`).
  3. Bổ sung kiểm tra an toàn kiểu dữ liệu cho `takenBy` (`typeof takenBy === 'string'`) trước khi gọi `.split()`.
  4. Đã kiểm thử tự động với headless Chrome DevTools Protocol mô phỏng click trực tiếp và build Vite thành công 100%.
